# **App Name**: VendasPro

## Core Features:

- Client Management: Import clients from Excel, manually add clients, and automatically retrieve company data via CNPJ from public APIs. Classify clients as 'Active Contract' or 'Occasional Client'.
- Sales Funnel: Manage sales opportunities through configurable stages (Lead, Contact, Proposal, Negotiation, Closed, Lost). Track status and assigned personnel.
- Proposal Generator: Create and send proposals with company logo, client data, products/services, and payment terms. Convert to PDF and send via email/WhatsApp with tracking.
- Automated Document Engine: Upload base templates (Word/PDF), define dynamic fields, and automatically generate final documents with previsualitzation. Confirms final file with the client before send and save send history.
- Calendar & Appointments: Integrate with Google Calendar for scheduling appointments related to clients and deals. Send automatic WhatsApp confirmations and reminders. Supports assigning multiple users to events.
- Issue Tracking & Support: Track support tickets/tasks with statuses (Open, In Progress, On Hold, Closed). Time tracking per agent and detailed history. Enforce actions upon completion and configurable SLAs per issue type.
- Intelligent Opportunity Suggestion Tool: Suggest relevant new sales opportunities for users based on historical sales data and customer profiles. LLM reasons when or if this information is important or beneficial for the end user

## Style Guidelines:

- Primary color: A rich blue (#3F51B5) evoking trust and reliability.
- Background color: A very light blue (#E8EAF6), providing a clean and professional backdrop.
- Accent color: A vibrant purple (#7E57C2) for highlighting key actions and elements.
- Font pairing: 'Poppins' (sans-serif) for headings and short blocks of text paired with 'PT Sans' (sans-serif) for longer passages of body text.
- Code font: 'Source Code Pro' for displaying code snippets within the app.
- Use clean, modern icons to represent different modules and actions, maintaining a consistent style throughout the interface.
- Incorporate subtle animations and transitions to provide feedback and enhance user experience, such as loading indicators and button hover effects.
